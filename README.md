# Van Gogh Inside — 인터랙티브 웹 포스터 (2024 중간고사)

빈센트 반 고흐의 작품 「별이 빛나는 밤」, 「아몬드 꽃」, 「해바라기」를 모티프로 만든 움직이는 웹 포스터입니다.

🔗 **바로 보기:** https://gaeun02.github.io/MovingPoster_24-Mid/

## 주요 인터랙션

- **별이 빛나는 밤** — 별이 반짝이고 별똥별이 떨어지는 애니메이션
- **아몬드 꽃** — 꽃잎이 원근감 있게 흩날리고, 마우스를 움직이면 그 자리에 꽃이 피어남
- **해바라기** — 해바라기와 꽃병 일러스트를 활용한 장면 구성

## 사용 기술

- HTML / CSS / JavaScript
- [jQuery](https://jquery.com/), [anime.js](https://animejs.com/)
- Google Fonts (Allura, Jua, Playfair Display, Satisfy)

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.
